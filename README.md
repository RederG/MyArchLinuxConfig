# My Arch Linux Configurations files

## Intro

Hello, my name is Rederg.
I recently installed Arch Linux as a virtual machine.
I want to store my config files (known as "dotfiles") on GitHub to use it later when I get a new PC.
Anyone who has a fresh Arch Linux install can install it and use my config.

## Content

This repo contains folders that represents "dotfiles" (hidden files in the system).
It also contains a script file written in the fish shell language that will install and configure every "fragments" of my configuration.
